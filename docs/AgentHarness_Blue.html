Understanding MoE

Mixture-of-Experts: giant models that use only a few experts per token. Save this.

1. Dense vs MoE

A dense layer runs every weight for every token. An MoE layer runs only the 2 experts the router picks.

router scores for one token (softmax)

2. The router picks top-k

A small linear layer scores all experts, softmax turns scores into weights, and only the top 2 are kept.

3. Where MoE lives

It replaces the feed-forward block inside each transformer layer. Attention stays dense and shared.

4. Total vs active parameters

Huge on disk, small per token. The model knows a lot but only pays compute for the experts it uses.

5. Keep the experts balanced

Left alone, the router overloads a few favourites. An auxiliary balancing loss spreads tokens evenly.

6. The catch: memory

Compute scales with active parameters, but every expert still has to sit in GPU memory.
